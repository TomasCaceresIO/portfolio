# Portfolio - Tomás Cáceres

Portafolio personal desarrollado con [Astro](https://astro.build/) y [Vite](https://vitejs.dev/).

## Tecnologías

- **Framework:** Astro
- **Bundler:** Vite
- **Runtime:** Node.js

## Inicio rápido

```bash
# Instalar dependencias
npm install

# Servidor de desarrollo
npm run dev

# Build de producción
npm run build
```
